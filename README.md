# CoD LAN Tracker

Stats des manches Search & Destroy du week-end LAN CoD : saisie partagée en direct, classements, vues joueur et map, tirage au sort, écran + musique de victoire.

- Site : GitHub Pages
- Base partagée : Firebase Firestore (config dans `firebase-config.js`)
- Sur le tél : ouvrir le lien puis « Ajouter à l'écran d'accueil »
